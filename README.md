# NestDirect
* This is real estate website where you connect directly with property owners
* You can browse properties if you are looking to buy
* If you want to list your property for sell, you need to register first
* When you register, you can manage your listings, favorites and messages from profile page
* Only registered users can send messages to other registered users
* Users can pay for featured, premium or elite marks on their listed properties
* If you want to delete account, you can do it from the profile page
